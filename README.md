# Unified Calendar（Webアプリ試作版）

このアプリは、**iPhone / Mac のカレンダー**や**Google カレンダー**で一般的な運用を参考にしながら、
「個人・会社・友人グループなどの予定を一元管理する」ことを目指した Web プロトタイプです。

---

## 1. このアプリでできること

- 月カレンダーを縦スクロールでなめらかに閲覧
- 予定の追加・編集・削除
- 予定の色分け（種別 + カラー）
- 予定に以下の詳細を設定
  - タイトル
  - 開始 / 終了日時
  - 場所
  - URL
  - 説明
- グループ共有（例: 会社、友人グループ）
- 共有権限の分離
  - `admin`（管理者）
  - `editor`（編集可）
  - `viewer`（閲覧のみ）
- 招待トークン（招待リンクの代替）によるグループ参加フロー

---

## 2. 起動方法

### 必要環境

- Python 3（ローカルHTTPサーバー起動用）
- ブラウザ（Chrome / Safari / Edge など）

### 手順

```bash
cd /workspace/Calendar
python3 -m http.server 5173
```

または、どのディレクトリにいても以下で起動できます。

```bash
python3 -m http.server 5173 --directory /workspace/Calendar
```

ブラウザで以下を開いてください。

- `http://localhost:5173`

> 補足: データは `localStorage` に保存されます。ブラウザのストレージを削除すると予定・グループ情報は消えます。

### 「Directory listing for /」が表示されるとき

これは **サーバーを `/`（ルート）で起動している** ときに起こります。

- `cd /workspace/Calendar` してから起動する
- もしくは `--directory /workspace/Calendar` を付けて起動する
- ブラウザURLが `http://localhost:5173/` になっているか確認する

上記で、カレンダー画面（`index.html`）が表示されます。

## 3. 画面の見方

### 上部バー

- **表示ユーザー**: 表示対象ユーザーを切り替え
- **今日へ**: 現在月へスムーズスクロール
- **予定を追加**: 予定作成ダイアログを開く
- **グループ作成**: 新しい共有グループを作る

### 左サイドバー

1. **表示カレンダー**
   - 「個人 / 会社 / 友人」をチェックON/OFFして表示切替
2. **共有グループ**
   - 自分が参加中のグループ一覧
   - 管理者は「招待リンク生成」（招待トークン発行）が可能
3. **招待リンク受け取り**
   - 受け取った招待トークンを入力し、参加承認画面へ進む

### メイン領域

- 月ごとのカレンダーが並びます
- 日付セル内の色付きチップが予定です
- 予定チップをクリックすると編集ダイアログが開きます

---

## 4. 予定の作成方法

1. **「予定を追加」**を押す
2. 以下を入力
   - タイトル（必須）
   - 種別（仕事 / 個人 / 友人 / 学習 / その他）
   - 色
   - 開始・終了日時（必須）
   - 場所 / URL / 説明（任意）
   - 共有先グループ（必要な場合）
3. **保存**

### ルール

- 終了日時は開始日時より後である必要があります
- 共有先グループを指定する場合、現在ユーザーにそのグループの編集権限が必要です

---

## 5. 予定の共有方法（グループ反映）

1. 予定作成・編集時に「共有先グループ」を選択
2. 保存すると、**そのグループのメンバーにも予定が表示**されます
3. ただし編集可否は権限に従います

### 権限の考え方

- `admin`: 招待発行、共有予定の編集可
- `editor`: 共有予定の編集可
- `viewer`: 閲覧のみ（編集不可）

これにより、グループ全員が同時に予定を編集して競合する問題を減らせます。

---

## 6. グループ作成〜招待フロー

### グループ作成

1. 「グループ作成」を押す
2. グループ名と説明を入力
3. 作成者は `admin` として登録されます

### 招待

1. `admin` がグループ一覧から「招待リンク生成」を押す
2. 招待トークンが発行されます（クリップボードコピーを試行）
3. 参加したいユーザーがトークンを「招待リンク受け取り」に入力
4. 招待確認ダイアログで「参加する」を押す
